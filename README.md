# 🚀 WhatsApp Multi-Session Automation Web App

একটি শক্তিশালী, ক্লাউড-ভিত্তিক মাল্টি-সেশন হোয়াটসঅ্যাপ অটোমেশন সিস্টেম। এটি `Node.js`, `Express`, `Socket.IO` এবং `whatsapp-web.js` (Puppeteer/Headless Chrome) ব্যবহার করে তৈরি করা হয়েছে। 

এই সিস্টেমের মাধ্যমে ইউজাররা ওয়েব ইন্টারফেস ব্যবহার করে নিজস্ব হোয়াটসঅ্যাপ নম্বর লিঙ্ক করতে পারে। সেশনগুলো সার্ভারে স্থায়ীভাবে সংরক্ষিত থাকে, ফলে ইউজার বা অ্যাডমিন অফলাইনে থাকলেও ব্যাকএন্ড ব্যাকগ্রাউন্ডে নিরবচ্ছিন্নভাবে কাজ চালিয়ে যায়।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)

* **সহজ পেয়ারিং সিস্টেম:** QR কোড স্ক্যান করার ঝামেলা ছাড়া সরাসরি ফোন নম্বর দিয়ে ২-৫ সেকেন্ডের মধ্যে পেয়ারিং কোড জেনারেশন।
* **মাল্টি-সেশন পারসিস্টেন্স:** `LocalAuth` ব্যবহার করে প্রতি নম্বরের জন্য আলাদা আলাদা সেশন ফোল্ডার সংরক্ষণ, যা সার্ভার রিস্টার্ট হলেও সক্রিয় থাকে।
* **Puppeteer / Headless Automation:** আসল WhatsApp Web ইন্টারফেস অটোমেট করার কারণে মিডিয়া (ছবি, ভয়েস, ডকুমেন্ট) পাঠাতে ও গ্রহণ করতে কোনো বাধা থাকে না।
* **এডমিন প্যানেল সাপোর্ট:** অ্যাডমিন প্যানেল থেকে যেকোনো সেভ হওয়া অ্যাকাউন্টে সুইচ করে মেসেজিং, এডিটিং ও ডিলিটিং পরিচালনা করা সম্ভব।
* **রিসোর্স অপটিমাইজেশন:** উবুন্টু সার্ভারে ২-৩ জিবি র‍্যামের মধ্যে দক্ষতার সাথে পরিচালনা করার উপযোগী।
